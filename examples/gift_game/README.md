# Gift game (tracked)

Starter Godot project with **AetherionEngine** + **API bible** script.

DLL is **not** in git. From the Aetherion repo root:

```powershell
cargo run -p aetherion-cli -- deploy --to examples/gift_game
# or menu g and paste this folder path
```

Then open this folder in Godot (or install --open) and press **Play**.

Source of the bible script: `templates/gift/aetherion_engine_api.gd` (re-copied on install).
